# M3U8 广告分片过滤器（Chrome 扩展）

自动识别并移除 HLS 视频流中注入的广告分片，消除"正片播到一半突然插广告、
音量突跳、声音断续"的问题。适用于 Tabbit / Chrome / Edge 等所有 Chromium 内核浏览器。

识别规则基于 6 个品类 / 25 条线路 / 15 个 CDN 的真实采样调优，
带站点开关与实时统计面板。

## 原理

很多影视站的广告不在网页代码里，而是**拼在视频源站的 m3u8 播放列表中间**
（被 `#EXT-X-DISCONTINUITY` 包裹的短分片块，插在正片分片之间）。
本扩展在浏览器网络层拦截 m3u8 响应，用启发式规则剔除广告分片后再交给播放器，
播放器永远请求不到广告分片，正片音画连续。

### 识别策略（纯内置启发式，无站点白名单、无远程规则表）

裁决总纲是"**宁漏勿误**"：高置信度才删，任何不确定的块只记数不删除。

- **Tier 1（确证即删）**
  - **A 路径关键词**：URI 含 `adjump`、`/ads/`、`/adv/` 等广告路径段（加速云/暴风系）
  - **C 编号三明治**：前后正片分片编号无缝衔接、中间短块跳号且 <90s（高清云/量子系）
  - **D 孤立短块+佐证**：被 DIS 包裹的 ≤10 片 <90s 中间块，其余块均 ≥30s，且帧率小数/重复 URI/时长均匀至少一条佐证（火箭云/非凡系，哈希命名赌博广告）
  - **E KEY 三明治**：`METHOD=NONE` 区段夹在两个真密钥区段间（标准 SSAI 广告插入）
  - **F dummy 分片**：EXTINF<0.1s 且 URI 重复的伪分片
- **Tier 2（组合判，总分 ≥1.5 且 ≥2 条信号才删）**：时长均匀 / 重复 URI / 帧率小数对比 / 目录前缀众数偏离 / host 偏离 / 绝对相对性偏离
- **保护机制**：master 播放列表、直播流、BYTERANGE 列表一律不碰；疑似广告占比 >30% 整单放弃；重组结果过安全器断言（首行 EXTM3U、ENDLIST 保留、只删不改、接缝恰好一个 DIS），任一失败返回原文

## 安装（Tabbit / Chrome / Edge 通用）

1. 打开浏览器的扩展管理页：
   - 地址栏输入 `chrome://extensions`（Tabbit/Chrome）或 `edge://extensions`（Edge）
2. 打开右上角（或左侧栏）的 **开发者模式** 开关
3. 点击 **加载已解压的扩展程序**（Load unpacked）
4. 选择本文件夹（`m3u8-ad-filter`，需包含 manifest.json 和 src/）
5. 完成。扩展对所有网站自动生效

更新版本时：回到扩展管理页，点击本扩展卡片上的 **刷新** 按钮，然后刷新视频页。

## popup 面板

点击浏览器工具栏的扩展图标：

- **站点开关**：当前站点一键启用/禁用（按域名持久化，刷新后仍生效）
- **实时统计**：检查/清洗的播放列表数、剔除的广告分片数、疑似广告（未删）数
- **最近处理**：最后清洗的 m3u8 地址（排障用）
- **清零统计 / 恢复默认**：重置计数 / 撤销本站点的开关覆盖

## 验证是否生效

方式一（推荐）：popup 面板看统计数字是否增长。

方式二：播放视频时按 F12，Console 里看日志：

```
[M3U8-AdFilter] 已剔除 5 个广告分片 <- https://...
```

或在 Console 输入 `__m3u8AdFilter`：

```json
{"playlistsChecked": 5, "playlistsCleaned": 5, "segmentsRemoved": 45, "suspects": 0, "lastUrl": "..."}
```

- `playlistsCleaned > 0` 表示有播放列表被净化过
- 无广告的站点该值为 0，属正常（过滤器静默放行）

## 实测记录

- **加速云（bfzym3u8，暴风系）**：`/video/adjump/time/` 9 片 26s 博彩广告，长片插 2 处（18 片）——规则 A，10/10 样本命中
- **高清云（lzm3u8，量子系）**：7 片 25.8s DIS 包裹块，插 1~3 处——规则 C 编号三明治，8/8 样本命中；159 个 DIS 噪声的密集列表（敢死队 4）安全通过
- **火箭云（ffm3u8，非凡系）**：32 位哈希命名 5 片 19.6s 均匀块（抽帧确认为赌博广告）——规则 D + 帧率小数佐证，命中且对 193-DIS 纯噪声列表零扰动
- **免费云（snm3u8）**：播放列表层零广告，9/9 样本 byte-identical 零扰动
- **真机（yhdmtv.cc）**：规则 D 删 5 片；开关禁用后原文放行、启用恢复清洗；跨 357s 删除接缝播放连续无卡顿

## 文件说明

- `manifest.json` — 扩展清单（MV3，MAIN/ISOLATED 双 world 注入，document_start 时机）
- `src/m3u8-engine.js` — 引擎：解析 → 重组 → 安全器（纯函数，Node 可测试）
- `src/rules.js` — 识别规则管道（Tier1/Tier2 裁决，纯函数）
- `src/filter-main.js` — MAIN world 拦截层（XHR + fetch 双通道 + 开关装卸）
- `src/bridge.js` — ISOLATED world 桥（chrome.* 与 MAIN 世界中转）
- `src/background.js` — service worker（开关解析 + 统计聚合）
- `popup/` — popup 面板（站点开关 + 统计）
- `demo/` — 回归测试（`node demo/run.js`，50 用例 + 对抗用例，任何规则改动必须全绿）
- `basic_code_information_archive/` `modification_log/` — 中文代码说明与修改日志

## 已知边界（如实告知）

- 广告在播放列表末尾（无后块可闭合三明治）、相邻双广告块、正片本身跳号：接受漏判
- Web Worker 内加载的 hls.js 是内容脚本硬盲区（特征：`__m3u8AdFilter.playlistsChecked` 不增长但视频在播）；目标站不命中此形态
- 隐藏 ID 型服务端映射广告在播放列表层零信号，明确不对抗
- `demo/samples/` 的真实采样不随仓库公开（含站点 CDN 地址），回归时按 `demo/README.md` 自行采样；安全器对抗用例不依赖样本，开箱即跑
